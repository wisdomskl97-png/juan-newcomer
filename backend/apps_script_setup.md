# Google Apps Script 배포 가이드

`backend/apps_script.gs`에 있는 코드를 실제로 동작하는 웹 API로 만드는 단계입니다. 스프레드시트 ID는 이미 코드에 넣어뒀습니다 (`1ddsa7WI80IDZT0YA1tSzhn1Ovw1NtLyuzHqAJK1uqwY`).

## 1. Apps Script 프로젝트 열기

1. 만드신 스프레드시트("주안 새가족 등록 DB")를 엽니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭.
3. 새 편집기 창이 열리고 기본 `Code.gs` 파일이 하나 있습니다.

## 2. 코드 붙여넣기

1. `Code.gs`의 기존 내용(`function myFunction() {}` 같은 기본 코드)을 전부 지웁니다.
2. `backend/apps_script.gs` 파일의 내용을 전부 복사해서 붙여넣습니다.
3. 저장 (⌘S 또는 저장 아이콘).

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 클릭.
2. 유형 선택(톱니바퀴 아이콘) → **웹 앱** 선택.
3. 설정:
   - 설명: `juan-newcomer v1` (아무 이름이나 무방)
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (새가족 폰에서 로그인 없이 호출해야 하므로 필수)
4. **배포** 클릭.
5. 처음 배포할 때 "승인 필요" 팝업이 뜨면 본인 Google 계정으로 승인 진행 (본인 소유 스프레드시트이므로 "안전하지 않음" 경고가 떠도 계속 진행해도 됩니다 — Google이 검증되지 않은 앱이라 보여주는 표준 경고입니다).
6. 배포가 끝나면 **웹 앱 URL**이 나옵니다. `https://script.google.com/macros/s/.../exec` 형태입니다. **이 URL을 저에게 알려주시면 3단계(프론트엔드 연동)에서 그대로 사용합니다.**

## 4. 동작 확인 (선택)

브라우저 주소창에 그 웹 앱 URL을 그대로 붙여넣고 열어보면:

```json
{"ok":true,"message":"주안 새가족등록 API is running"}
```

이렇게 나오면 정상 배포된 것입니다.

## 5. 코드를 수정한 뒤에는

`apps_script.gs` 내용을 나중에 다시 수정하게 되면, 저장만으로는 배포된 웹 앱에 반영되지 않습니다. **배포 → 배포 관리 → 연필(수정) 아이콘 → 버전: 새 버전 → 배포**를 다시 눌러야 실제 URL에 최신 코드가 반영됩니다. (URL 자체는 바뀌지 않습니다.)

---

## 참고: 이 API가 하는 일

- `action: "submitGeneral"` — 일반목장 새가족 전체 정보를 `Newcomers` 탭에 저장하고, `DailySummary` 탭에는 이름+태어난해만 추가로 기록합니다.
- `action: "submitUnivSummary"` — 대학목장 새가족은 **이름과 생년월일만** 받아서 `DailySummary` 탭에 이름+태어난해만 기록합니다. 연락처·비자·전공 등 상세 정보는 이 API에 아예 보내지 않는 것이 원칙이라, 서버에는 처음부터 도달하지 않습니다 (확정 기획 "옵션 A" 그대로).

3단계(프론트엔드 연동)에서 이 URL을 `script.js`에 넣고 `fetch`로 호출하도록 코드를 수정할 예정입니다.
