# 주안 새가족등록 앱 리뷰 (2026-08-16)

> 대상: `docs/`(프론트엔드) + `backend/apps_script.gs`(백엔드) — 실사용 테스트를 거치며 계속 수정해온 현재 배포 버전 기준. 등록자(새가족)와 팀원, 두 사용자 입장에서 정리했습니다.

## 총평

MVP로 시작해서 실사용 중 나온 문제들(한글 입력 깨짐, 뒤로가기, 날짜 롤업, 연락처 0 소실, 수정/삭제 미반영 등)을 하나씩 잡아오면서 지금은 등록→저장→팀조회→수정/삭제까지 전체 흐름이 실제 데이터로 안정적으로 동작하는 상태입니다. 다만 처음 기획안에 있었지만 아직 구현되지 않은 기능(개인정보 동의, 연락상태 관리, 중복 감지)과, 개발 과정에서 원칙이 바뀐 부분(대학목장 개인정보 최소화 폐기)이 정리가 필요합니다.

---

## 1. 등록자(새가족) 입장

### 좋은 점

- **빠른 등록 경로**: QR 스캔 → 목장분류 → 폼 → 완료까지 1~2분 내 가능. 단계가 짧고 화면 전환이 명확함.
- **목장 분류가 첫 화면에 강제 배치**: "예/아니오" 두 개의 큰 버튼으로 명확하게 구분되어, 실수로 잘못된 흐름에 들어갈 위험이 적음.
- **한국어/영어 병기**: 라벨 전체에 일관되게 적용되어 영어가 편한 새가족도 무리 없이 사용 가능.
- **생년월일 숫자 직접 입력**: 처음엔 달력 피커였는데, 스크롤이 느리다는 피드백을 받아 "19950101" 형태로 타이핑하면 자동으로 "1995-01-01"이 되는 방식으로 바꿈 — 나이 든 새가족도 빠르게 입력 가능.
- **가족 단위 연속 등록**: 완료 화면의 "한 명 더 등록하기"로 같은 폰으로 여러 명 등록 가능.
- **새로고침에 강함**: 등록 중간에 실수로 새로고침해도 입력하던 내용과 화면이 그대로 유지됨 (이전엔 홈으로 튕겨서 처음부터 다시 써야 했음).
- **제출 실패 시 데이터 보존**: 네트워크 문제로 제출이 실패해도 입력한 내용이 사라지지 않고, 에러 메시지와 함께 재시도 가능.
- **카카오톡 ID 찾는 법 안내**: 실제 현장에서 자주 헷갈리는 부분을 팝업으로 미리 챙김.

### 불편한 점 / 개선 포인트

- **개인정보 수집·이용 동의 절차가 없음**: 기획 단계부터 계획했던 항목인데 실제 화면에는 체크박스도, 안내 문구도 없습니다. 실제 배포 전에 반드시 넣어야 할 항목입니다.
- **대학목장도 이제 상세정보가 저장되는데, 새가족은 이 사실을 모름**: 원래 "대학목장은 저장 없이 대학팀 전달용으로만 쓰인다"는 안내를 염두에 뒀었는데, 지금은 일반목장과 똑같이 연락처·비자 등이 시트에 저장됩니다. 그런데 화면에는 여전히 "정보를 남겨주시면 대학팀에서 연락드립니다" 정도의 안내만 있고, "저장된다"는 사실이 명시되어 있지 않습니다. 동의 절차와 함께 정리가 필요합니다.
- **QR로 처음 들어왔을 때 뒤로가기가 가끔 카메라(스캐너)로 나가버림**: 화면 안에서 이전 단계로 가는 게 아니라 앱을 완전히 벗어나는 경우가 있음 (원인은 파악했지만 아직 미해결 — 다음 작업으로 보류 중).
- **팀원이 대신 입력하는 경우를 구분할 방법이 없음**: 기획 초기엔 "등록경로(QR/팀원입력)"를 구분하려 했는데, 지금은 항상 "QR"로 고정 기록되어 실제로 누가 입력했는지 시트에서 구분이 안 됩니다.

## 2. 팀원 입장

### 좋은 점

- **팀 요약이 이제 진짜 시트 데이터**: 처음엔 브라우저 메모리에만 있어서 새로고침하면 사라지는 문제가 있었는데, 지금은 매번 시트에서 실제로 불러옵니다. 다른 기기에서 봐도 같은 데이터가 보입니다.
- **오늘 등록은 자동으로 이번 주일 날짜로 묶임**: 월~토요일에 등록해도 다가오는 주일 날짜로 자동 정리되어, 주일에 팀원이 확인하면 그 주에 등록한 사람이 전부 "오늘" 탭에 모여 있음.
- **수정/삭제가 실제로 시트에 반영됨**: 팀요약에서 정보를 고치거나 삭제하면 시트까지 반영되고, 삭제는 소프트 삭제라 실수해도 시트에서 복구 가능.
- **일반/대학목장 필터 + 지난 기록(월/주) 탐색**: 오늘 것뿐 아니라 과거 기록도 월/주 단위로 찾아볼 수 있음.
- **연락처 앞자리 0 문제 해결**: 구글시트가 숫자로 자동 변환해버려서 04로 시작하는 번호가 깨지던 문제를 고쳐서, 이제 정확한 번호가 그대로 보임.
- **등록 요약 미리보기 + 복사/공유 통합**: 버튼 하나로 미리보기 → 그 안에서 복사 또는 공유 선택 가능.
- **대학목장 전달 메시지 자동 생성**: 그날 등록한 대학목장 대상자 정보를 모아 대학팀에 바로 전달할 메시지를 만들어줌.
- **새로고침해도 팀요약 화면 유지, 새로고침 버튼도 별도 제공**: 화면을 벗어나지 않고 최신 데이터만 다시 불러올 수 있음.

### 불편한 점 / 개선 포인트

- **연락 상태·담당자·메모를 앱에서 관리 못 함**: 시트 스키마엔 `follow_up_status`(미연락/연락완료/목장연결/정착완료), `담당자`, `메모` 칸이 있지만, 앱 화면에서는 전혀 손댈 수 없고 시트를 직접 열어야 합니다. 팀요약의 "수정" 카드에 이 항목들을 추가하면 앱만으로 후속 관리가 가능해집니다.
- **지난 기록은 조회만 가능, 수정/삭제 불가**: "오늘" 탭에서만 수정·삭제 버튼이 동작합니다. 지난 주 등록자 정보에 오탈자가 있어도 앱에서 못 고치고 시트에서 직접 고쳐야 합니다.
- **중복 연락처 감지 기능 없음**: 같은 사람이 실수로 두 번 등록해도 팀원에게 알려주지 않습니다.
- **신규 등록 알림 없음**: 새가족이 등록해도 팀원에게 실시간으로 알려주는 기능이 없어서, 팀원이 직접 팀요약 화면을 열어봐야 압니다.
- **PIN이 팀 전체 공용, 개인별 구분 없음**: 누가 수정/삭제했는지 기록이 안 남습니다. 소프트 삭제 덕분에 복구는 가능하지만, "누가" 그랬는지는 알 수 없습니다.

## 3. 공통 / 운영 관점 참고사항

- **개인정보 처리 원칙이 처음 기획과 달라짐**: 원래 "대학목장은 최소정보만, 저장 안 함"이었는데 지금은 일반목장과 동일하게 전체 저장합니다. 실제 서비스 오픈 전에 이 부분을 새가족에게 어떻게 안내할지(동의 문구 등) 정리가 필요합니다.
- **Apps Script 배포 과정이 여전히 수동**: 코드 수정할 때마다 에디터에 붙여넣고 "새 버전으로 배포"를 눌러야 하는데, 이 단계를 깜빡해서 여러 번 옛날 코드가 계속 돌아가는 문제가 있었습니다. 팀 내에서 이 배포 담당자와 절차를 명확히 해두는 게 좋겠습니다.
- **테스트 데이터가 실제 시트에 여러 번 섞여 들어감**: 개발 중 curl로 직접 테스트한 데이터들이 `Newcomers`/`DailySummary`에 남아있을 수 있습니다. 실제 운영 전에 한 번 정리(또는 시트 초기화)가 필요합니다.
- **팀 PIN이 소스코드에 그대로 노출됨**: 저장소가 Public이라 코드를 보면 PIN을 알 수 있습니다. 지금은 "이름+태어난해 정도만 보호하는 약한 잠금"이라는 전제로 받아들이기로 한 부분이라 문제는 아니지만, 상세정보(연락처 등)까지 보이는 지금 상황에서는 재검토할 가치가 있습니다.

## 4. 우선순위 제안

**지금 바로 처리하면 좋은 것**
1. 개인정보 수집·이용 동의 체크박스 추가 (일반/대학목장 폼 둘 다)
2. 대학목장 안내 문구를 "정보가 저장된다"는 사실에 맞게 수정
3. 테스트 데이터 정리

**다음 기능 확장으로 좋은 것**
4. 팀요약 수정 카드에 연락상태/담당자/메모 추가
5. 지난 기록도 수정 가능하게 확장
6. 중복 연락처 감지

**여유 있을 때**
7. QR 최초 진입 시 뒤로가기 → 카메라 이슈
8. 신규 등록 알림
9. 등록경로(QR/팀원입력) 구분
